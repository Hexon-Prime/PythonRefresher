## Quick Setup (VS Code)

1. **Install Python:** Download Python 3 from [python.org](https://www.python.org/downloads/) (make sure to check **Add python.exe to PATH** on Windows). Verify in your terminal with `python --version` or `python3 --version`.
2. **Install VS Code Extension:** Open Extensions (`Ctrl+Shift+X` / `Cmd+Shift+X`) and install the official **Python** extension by Microsoft.
3. **Run a File:** Open your project folder in VS Code, create a `.py` file (e.g., `main.py`), and run it using the **Run Python File** button at the top right or via terminal:
   ```bash
   python main.py
